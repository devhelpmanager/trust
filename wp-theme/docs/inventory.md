# Инвентарь «макет → блок / шаблон»

Шаг 0.1 плана работ. Документ показывает, в какой элемент темы превращается каждая секция
каждого макета, какие у элемента поля и откуда берутся данные. Номер в колонке «Шаг» —
шаг плана, на котором элемент делается (план — в конце документа).

Обозначения:

- **Блок** `trust/…` — блок редактора (Gutenberg) с полями SCF. Вёрстка в `blocks/<имя>/render.php`.
- **Шаблон** — PHP-файл темы. Тексты шаблонов редактируются в «Настройках сайта → Тексты шаблонов».
- **Настройки → …** — вкладка страницы «Настройки сайта».
- **Авто** — значение вычисляет тема (номера, счётчики, даты, крошки).
- Тексты, цифры и заглушки `[…]` из макетов попадают **только** в значения по умолчанию полей
  и в демо-контент, а не в код темы.
