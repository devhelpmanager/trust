# Шаблон страницы услуги

Откройте `index.html` двойным щелчком в любом браузере. Это один самостоятельный файл:
разметка, стили и скрипты внутри, поэтому меню, выпадающие списки и анимации работают
так же, как на холсте.

## Из чего состоит страница

1. **Шапка** (цвет индиго #1E1B4B): логотип, телефон, email, кнопка «Заказать обратный звонок»,
   меню с выпадающими списками (SEO, GEO, Контекстная реклама, О нас). Списки открываются
   при наведении и по клику. На экранах уже 1180 px меню сворачивается в кнопку-бургер
   с раскрывающимися подменю; в шапке остаются логотип, телефон и кнопка звонка
   (на телефонах — только логотип, иконка звонка и бургер, email и телефон есть в меню).
2. **Заголовок страницы**: хлебные крошки, H1 «Технический аудит сайта», кнопки.
3. **Блоки**: «Что включает услуга», «Этапы работы», «Наши преимущества», «Вопрос-ответ»,
   «Кнопка связи» (свайп для отправки).
4. **Наш блог**: пять последних статей.
5. **Подвал** (индиго): описание и логотип, «Услуги», «Компания», контакты, юридическая информация.

Шрифты (Unbounded, Onest, JetBrains Mono) подключаются из Google Fonts — для точного вида нужен
интернет. Без него страница покажется системным шрифтом, но всё будет работать.

## Что заменить

- `[Бренд]`, телефон `+7 (000) 000-00-00`, `hello@example.ru`, `[Адрес офиса]`, `[Часы работы]`.
- Юридические данные: `[год]`, `[Юридическое название]`, ИНН, ОГРН, `[Юридический адрес]`.
- Цены `от X XXX ₽`, даты статей `[дата]`.
- Ссылки вида `#seo-audit`, `#privacy` — на реальные страницы сайта.
- Формы ничего не отправляют: обработку заявок подключает разработчик.

## Для разработчика

Каждый блок лежит в `<template id="dc-tpl-…">`, его логика — в вызове `DC.register(…)`
(класс с методом `renderVals()`, состояние меняется через `setState`). Блоки подключаются
в разметку страницы тегом `<dc-import name="…">`. Чтобы убрать или переставить блок,
достаточно убрать или переставить соответствующую строку `<dc-import>` в шаблоне `Main`.
