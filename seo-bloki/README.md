# Блоки страниц услуг

## Как открыть

- `index.html` — все 17 блоков на одной странице. Откройте двойным щелчком в любом браузере.
- `01-tarify.html` … `17-cookie.html` — каждый блок отдельным файлом. Файл самостоятельный: в нём есть разметка, стили и скрипт, поэтому все анимации и кнопки работают так же, как на холсте.
- `images/` — изображения для блоков 12 и 14. Держите папку рядом с HTML-файлами.

Шрифты (Unbounded, Onest, JetBrains Mono) подключаются из Google Fonts, поэтому для точного вида нужен интернет. Без него блоки покажутся системным шрифтом, но всё будет работать.

## Что заменить перед публикацией

- Цены `XX XXX ₽` и `−XX%` (блоки 1, 4, 13).
- Имена `[Имя Фамилия]`, должности, даты `[дата]`, `[Регион]`, `[N]`.
- Блоки 12 и 14: названия проектов, запросы, позиции и скриншоты — демонстрационные. Замените их реальными данными и скриншотами (файлы в `images/`).
- Блок 15: тексты отзывов, имена и фото — заготовки под реальные отзывы клиентов.
- Блок 11 (короткий): адрес `example@site.com`.
- Ссылки вида `#order`, `#privacy`, `#robots` — на реальные страницы сайта.
- Капча в блоке 7 — место под виджет (например, Яндекс SmartCaptcha).
- Формы ничего не отправляют: обработку заявок подключает разработчик.

## Для разработчика

Каждый файл устроен одинаково:

1. `<template id="dc-template">` — разметка блока со стилями прямо в атрибутах `style`. Значения в `{{ ... }}` — то, что меняется при взаимодействии (открыт/закрыт пункт, выбранная вкладка, положение свайпа). `<sc-if value="{{...}}">` — фрагмент, который показывается только при выполнении условия.
2. Первый `<script>` — маленький движок (~150 строк без зависимостей): подставляет значения, показывает и скрывает фрагменты, навешивает обработчики событий.
3. Второй `<script>` — логика блока: класс `Component`, метод `renderVals()` возвращает значения и обработчики. Состояние меняется через `this.setState(...)`.

Блоки можно встроить на сайт как есть (например, через `iframe` или вставкой HTML-кода в конструктор) или переписать логику на фреймворк вашего сайта. Вся логика каждого блока занимает несколько десятков строк.
